> 补充：基于数学规划的网络瓦解方法有：
> **一、传统方法**
> 1.线性规划方法
> 线性规划是一种数学优化技术，可用于求解网络中的最优路径、最大流、最小费用流等问题。在网络瓦解中，线性规划可确定如何最有效地移除或破坏网络中的关键节点或链路，以达到瓦解网络的目的。例如在电力网络规划中，线性规划能用来确定哪些电力线路或变电站应该被优先关闭或破坏，以最小化对电网的影响或达到某种特定的战略目标。
> 2.整数规划方法
> 整数规划是线性规划的一种特殊形式，其中所有的决策变量都必须是整数。在网络瓦解中，整数规划可用于求解那些需要离散决策的问题，比如选择哪些节点或链路进行攻击或防御。通过整数规划，可以找到一种最优的离散决策方案，以最大化网络瓦解的效果。
> 3.非线性规划方法
> 对于某些复杂的网络瓦解问题，线性或整数规划可能无法提供足够的灵活性来描述问题的全部特性。非线性规划方法允许目标函数和约束条件是非线性的，从而能够更准确地描述网络瓦解问题的实际特性。
> 4.网络流优化方法
> 网络流优化是网络科学中的一个重要领域，它研究如何在网络中有效地传输流量。在网络瓦解中，网络流优化方法可以被用来分析网络中的流量分布，并确定如何通过破坏或移除某些节点或链路来最大化地干扰或阻断网络流量。
> 5.启发式算法
> 启发式算法通常基于某种直观或经验性的规则来搜索问题的解空间，并找到一种近似最优的解。虽然启发式算法可能无法保证找到全局最优解，但它们通常能够在较短的时间内找到一种可行的解，并且对于大规模的网络瓦解问题来说，启发式算法可能是唯一可行的解决方案。
> **二、比较感兴趣的其他重要方法**
> 1.不完全信息条件下基于链路预测的复杂网络瓦解问题
> 研究背景：在实际的网络环境中，我们往往无法获取网络的全部信息，例如在反恐维稳中面对恐怖组织网络、疾病免疫中面对疾病传播网络等，这些网络可能存在部分信息缺失的情况。但我们又需要通过免疫、封锁、隔离、干扰、袭击等手段有效瓦解这些有害网络，其核心任务是找到网络系统的“关键节点”。
> 方法：创新提出基于链路预测的新思路，探索通过链路预测还原部分缺失的网络结构信息，从而提高网络瓦解效果。具体包括构建不完全信息条件下基于链路预测的复杂网络瓦解模型，研究已知信息、未知信息、预测信息等多源信息融合的形式化描述；分析信息缺失对复杂网络瓦解效果的影响；构建基于链路预测的复杂网络瓦解策略优化模型并给出求解算法，定量分析链路预测对网络瓦解效果的贡献；解决链路预测应用过程中的预测算法逃选以及预测比例确定问题等。
> 意义：为解决反恐维稳、疾病免疫、军事对抗等不完全信息条件下的复杂网络瓦解问题提供新思路、新技术，同时也为链路预测在其他领域的应用提供重要借鉴。

## _5.2 网络鲁棒性测度指标_

**掌握相关指标及其含义**


| 名称         | 含义                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| 网络直径     | 所有节点对之间最短路径长度的最大值                                             |
| 最大连通片   | 当前网络中包含节点数量最多的连通子图                                           |
| 临界移除比例 | 在给定攻击策略下，使网络瘫痪（最大连通片规模小于阈值）所需要移除的最小节点比例 |
| Schneider R  | 综合考虑不同攻击强度对网络连通性造成的影响的指标                               |
| 自然连通度   | 通过计算网络中不同长度闭路径数目的加权和，刻画网络中替代路径的冗余性           |

网络遭受攻击后，

- 网络直径变化越小
- 最大连通片规模变化越小
- 临界移除比例越大
- R值越高
- 自然连通度越大

则网络鲁棒性越强。

**源代码：**

```sh
def natural_connectivity(G):
    # 计算图 G 的邻接矩阵的特征值
    eig_value = np.linalg.eigvals(nx.to_numpy_matrix(G))
    # 计算特征值的指数
    exp_eig = np.exp(eig_value)
    # 计算特征值的指数和除以图的节点数量，然后取对数
```

**4.生成树计算**
**源代码：**

```sh
def calculate_spanning_trees(G):
    # 计算网络的拉普拉斯矩阵
    L = nx.laplacian_matrix(G).toarray()
  
    # 移除第一行和第一列，得到L的导出矩阵
    L_minor = np.delete(np.delete(L, 0, axis=0), 0, axis=1)
  
    # 计算拉普拉斯矩阵的导出矩阵的行列式
    determinant = np.linalg.det(L_minor)
  
    # 生成树数量即为行列式的值
    num_spanning_trees = int(round(determinant))
    return num_spanning_trees
```

### _5.3.1 随机失效_

**定义**
指在网络中以均等的概率随机地移除节点或边的扰动策略。适用于模拟非故意破坏导致的故障，例如自然灾害引发的山体滑坡和道路损毁，或设备故障导致的传输设备损坏等情形。

- 随机性
- 概率相等

**补充练习**
对ER图和BA图每次移除一定比例的节点，从0到1，每次增加0.01的比例。对于每个移除比例，计算剩余网络的最大连通片的大小，并记录下来。
基本思路：先构建网络，再模拟节点移除，计算最大连通片，最后可视化结果。
最后生成一个折线图，显示在随机移除节点的情况下，ER 图和 BA 图的最大连通片规模的变化趋势。

```sh
import networkx as nx 
import matplotlib.pyplot  as plt 
import random 
 
def calculate_largest_component_size(G, removal_fraction):
   # G: 网络图
   #removal_fraction: 移除的节点比例（0 <= removal_fraction <= 1）
   #计算在移除一定比例的节点后，网络的最大连通片的相对大小,返回最大连通片的相对大小（相对于原始网络的节点数）

    # 复制原始图以避免修改原始图 
    G_copy = G.copy() 
  
    # 计算要移除的节点数量 
    num_nodes = len(G_copy.nodes()) 
    nodes_to_remove = int(num_nodes * removal_fraction)
  
    # 随机选择要移除的节点 
    all_nodes = list(G_copy.nodes()) 
    removed_nodes = random.sample(all_nodes,  nodes_to_remove)
  
    # 移除节点 
    for node in removed_nodes:
        G_copy.remove_node(node) 
  
    # 计算所有连通片的大小 
    components = nx.connected_components(G_copy) 
    component_sizes = [len(component) for component in components]
  
    # 找到最大连通片的大小 
    if component_sizes:
        max_component_size = max(component_sizes)
    else:
        max_component_size = 0 
  
    # 计算相对大小 
    relative_size = max_component_size / num_nodes 
    return relative_size 
 
# 生成一个随机图（ER图）
n = 1000  # 节点数 
p = 0.01  # 边存在的概率 
G_er = nx.erdos_renyi_graph(n,  p)
 
# 生成一个无标度网络（BA图）
m = 3  # 每次添加的新节点连接的现有节点数 
G_ba = nx.barabasi_albert_graph(n,  m)
 
# 定义移除比例范围 
removal_fractions = [i/100 for i in range(0, 100)]
 
# 存储结果 
results_er = []
results_ba = []
 
# 对ER图进行模拟 
for frac in removal_fractions:
    avg_size = 0

        size = calculate_largest_component_size(G_er, frac)
        avg_size += size 
    results_er.append(avg_size  / 10)
 
# 对BA图进行模拟 
for frac in removal_fractions:
    avg_size = 0 
    for _ in range(10):  # 多次模拟取平均 
        size = calculate_largest_component_size(G_ba, frac)
        avg_size += size 
    results_ba.append(avg_size  / 10)
 
# 绘制结果 
plt.figure(figsize=(10,  6))
plt.plot(removal_fractions,  results_er, label='ER Network')
plt.plot(removal_fractions,  results_ba, label='BA Network')
plt.xlabel('Fraction  of Removed Nodes')
```

### _5.3.2 蓄意攻击_

**定义**
又称目标攻击，是指按照一定的重要性规则（例如基于中心性指标）有针对性地移除网络中的节点或边的攻击策略。相比于随机失效，蓄意攻击对网络造成的危害性更大。

**资料示例**
通过NetwoekX库模拟对ER网络和BA网络的随机失效与基于度中心性的蓄意攻击，定义数组记录最大连通子图节点数的变化，并判断网络是否瓦解。
**代码**

```sh
import numpy as np
import networkx as nx
import random
from copy import deepcopy

# 计算网络度的二阶矩
def calculate_degree_second_moment(G):
    degrees = [d for n, d in G.degree()]
    if len(degrees) == 0:
        return 0
    return np.mean([d ** 2 for d in degrees])

# 计算网络的平均度
def calculate_average_degree(G):
    degrees = [d for n, d in G.degree()]
    if len(degrees) == 0:
        return 0
    return np.mean(degrees)
  
def simulate_attack(G_, attack_type='random'):
    # 模拟网络攻击，包括随机失效和基于度的蓄意攻击，记录每次移除节点后最大连通子图的比例
    G = deepcopy(G_)  # 创建网络的深拷贝，避免修改原始网络
    number_of_nodes = G.number_of_nodes()  # 获取网络的节点数
    largest_all = np.zeros(number_of_nodes + 1) 
    # 初始化数组，用于记录每次攻击后最大连通子图的比例
    recorded_pc = False  # 标志位，用于记录临界移除比例
    nodes_sorted_by_degree = sorted(G.nodes(), key=lambda n: G.degree(n), reverse=True)  # 根据度从高到低排序节点

    for i in range(number_of_nodes):
        if G.number_of_nodes() == 0:
            break  # 如果所有节点都被移除，则退出循环
        largest_cc = len(max(nx.connected_components(G), key=len))  # 计算最大连通子图的大小
        largest_all[i] = largest_cc / number_of_nodes  # 记录最大连通子图的比例

        if attack_type == 'random':
            remove_nodes = random.sample(list(G.nodes()), 1)
            G.remove_nodes_from(remove_nodes)  # 随机移除一个节点
        elif attack_type == 'degree':
            remove_nodes = [nodes_sorted_by_degree[i]]  # 按照节点度从高到低移除一个节点
            G.remove_nodes_from(remove_nodes)

        if not recorded_pc and calculate_degree_second_moment(G) / calculate_average_degree(G) <= 2:
            pc = (i + 1) / number_of_nodes  # 记录渗流阈值
            recorded_pc = True  # 更新标志位

    if not recorded_pc:
        pc = 1.0  # 如果没有记录到pc值，则默认pc值为1.0

    return largest_all, pc  # 返回每次攻击后最大连通子图的比例数组和pc值

```

### _5.3.3 迭代攻击_

**定义**
是指在每次攻击后按照中心性计算规则重新计算残存网络中节点和边的重要性，并从中移除重要性最高的节点或者边。

**实践案例**
通过NetwoekX库模拟对BA网络的蓄意攻击与基于介数的迭代攻击，定义数组记录每次移除节点后网络最大连通片规模S的变化，并判断网络是否瓦解。
**核心代码**

```sh
import numpy as np
import networkx as nx
import random
from copy import deepcopy


# 计算网络度的二阶矩
def calculate_degree_second_moment(G):
    degrees = [d for n, d in G.degree()]
    if len(degrees) == 0:
        return 0
    return np.mean([d ** 2 for d in degrees])


# 计算网络的平均度
def calculate_average_degree(G):
    degrees = [d for n, d in G.degree()]
    if len(degrees) == 0:
        return 0
    return np.mean(degrees)


def simulate_attack(G_, attack_type='random'):
    """
    模拟网络攻击，包括随机失效和基于度的蓄意攻击，记录每次移除节点后最大连通子图的比例
    """
    G = deepcopy(G_)  # 创建网络的深拷贝，避免修改原始网络
    number_of_nodes = G.number_of_nodes()  # 获取网络的节点数
    largest_all = np.zeros(number_of_nodes + 1)  # 初始化数组，用于记录每次攻击后最大连通子图的比例
    recorded_pc = False  # 标志位，用于记录临界移除比例
    nodes_sorted_by_degree = sorted(G.nodes(), key=lambda n: G.degree(n), reverse=True)  # 根据度从高到低排序节点

    for i in range(number_of_nodes):
        if G.number_of_nodes() == 0:
            break  # 如果所有节点都被移除，则退出循环
        largest_cc = len(max(nx.connected_components(G), key=len))  # 计算最大连通子图的大小
        largest_all[i] = largest_cc / number_of_nodes  # 记录最大连通子图的比例

        if attack_type == 'random':
            remove_nodes = random.sample(list(G.nodes()), 1)
            G.remove_nodes_from(remove_nodes)  # 随机移除一个节点
        elif attack_type == 'degree':
            remove_nodes = [nodes_sorted_by_degree[i]]  # 按照节点度从高到低移除一个节点
            G.remove_nodes_from(remove_nodes)

        if not recorded_pc and calculate_degree_second_moment(G) / calculate_average_degree(G) <= 2:
            pc = (i + 1) / number_of_nodes  # 记录渗流阈值
            recorded_pc = True  # 更新标志位

    if not recorded_pc:
        pc = 1.0  # 如果没有记录到pc值，则默认pc值为1.0

    return largest_all, pc  # 返回每次攻击后最大连通子图的比例数组和pc值


def remove_nodes_by_betweenness(G):
    """
    按照节点介数从高到低移除网络中的一个节点
    """
    betweenness = nx.betweenness_centrality(G)  # 计算所有节点的介数中心性
    nodes_sorted_by_betweenness = sorted(betweenness.keys(), key=lambda n: betweenness[n], reverse=True)  # 根据介数从高到低排序节点
    remove_nodes = nodes_sorted_by_betweenness[:1]  # 选择介数最高的一个节点
    G.remove_nodes_from(remove_nodes)  # 从网络中移除该节点


def remove_nodes_by_degree(G):
    """
    按照节点度从高到低移除网络中的一个节点
    """
    nodes_sorted_by_degree = sorted(G.nodes(), key=lambda n: G.degree(n), reverse=True)  # 根据度从高到低排序节点
    remove_nodes = nodes_sorted_by_degree[:1]  # 选择度最高的一个节点
    G.remove_nodes_from(remove_nodes)  # 从网络中移除该节点


def iterative_attack(G_, attack_type='degree'):
    """
    模拟迭代攻击，包括基于度和基于介数的攻击，记录每次移除节点后最大连通子图的比例
    """
    G = deepcopy(G_)  # 创建网络的深拷贝，避免修改原始网络
    number_of_nodes = G.number_of_nodes()  # 获取网络的节点数
    largest_all = np.zeros(number_of_nodes + 1)  # 初始化数组，用于记录每次攻击后最大连通子图的比例
    recorded_pc = False  # 标志位，用于记录pc值

    for i in range(number_of_nodes):
        if G.number_of_nodes() == 0:
            break  # 如果所有节点都被移除，则退出循环
        largest_cc = len(max(nx.connected_components(G), key=len))  # 计算最大连通子图的大小
        largest_all[i] = largest_cc / number_of_nodes  # 记录最大连通子图的比例

        if attack_type == 'degree':
            remove_nodes_by_degree(G)  # 移除当前网络度最高的一个节点
        elif attack_type == 'betweenness':
            remove_nodes_by_betweenness(G)  # 移除当前网络介数最高的一个节点，这里是迭代攻击的核心代码

        if not recorded_pc and calculate_degree_second_moment(G) / calculate_average_degree(G) <= 2:
            pc = (i + 1) / number_of_nodes  # 记录渗流阈值
            recorded_pc = True  # 更新标志位

    if not recorded_pc:
        pc = 1.0  # 如果没有记录到pc值，则默认pc值为1.0

    return largest_all, pc  # 返回每次攻击后最大连通子图的比例数组和pc值
```

### _5.3.4 级联失效_

**定义**
指系统内的故障沿着要素间的耦合关系传播，导致其他要素接连失效的过程。
**主要模型**

- CASCADE模型：将以崩溃节点处的负载平均分配到仍在运行的节点上；初始负载和故障阈值相同。
- OPA模型：模拟实际电力网络的传输特性及其对负载和损失的优化过程。
- 负载-容量模型：网络中剩余节点的负载按正比于节点容量的方式分配给其邻居节点；初始负载跟节点的度相关。

**核心代码**

```sh
import numpy as np
import networkx as nx
import random
from copy import deepcopy


def initialize_load_capacity_degree_based(G, beta):
    """
    初始化节点的负载和容量，基于度中心性。

    参数:
    G (networkx.Graph): 要初始化的图。
    beta (float): 容量系数，决定节点容量相对于其度的倍数。
    """
    for node in G.nodes():
        degree = G.degree[node]  # 获取节点的度
        G.nodes[node]['load'] = degree  # 初始负载与节点度成正比
        G.nodes[node]['capacity'] = (1 + beta) * degree  # 容量为节点度的 (1 + beta) 倍

def perform_cascade_failure(G):
    """
    执行级联失效过程。

    参数:
    G (networkx.Graph): 要执行级联失效的图。

    返回:
    float: 最大连通子图的比例。
    """
    while True:
        new_failures = []  # 存储新的失效节点
        for node in G.nodes():
            if G.nodes[node]['load'] > G.nodes[node]['capacity']:  # 如果节点负载超过其容量
                new_failures.append(node)  # 节点失效
        if not new_failures:
            break  # 如果没有新的失效节点，结束循环
        # 重新分配失效节点的负载
        for node in new_failures:
            load_to_redistribute = G.nodes[node]['load']  # 获取失效节点的负载
            neighbors = list(G.neighbors(node))  # 获取失效节点的邻居节点
            if len(neighbors) > 0:
                redistributed_load = load_to_redistribute / len(neighbors)
                for neighbor in neighbors:
                    G.nodes[neighbor]['load'] += redistributed_load  # 负载均等分配给邻居节点
        # 从网络中移除失效节点
        G.remove_nodes_from(new_failures)
    # 找到最大的连通子图
    if len(G) > 0:
        largest_cc = max(nx.connected_components(G), key=len)  # 找到最大连通子图
        return len(largest_cc) / len(G.nodes())  # 返回最大连通子图的比例
    else:
        return 0  # 如果网络为空，返回0


def simulate_cascade_failure(removal_ratio, G, attack_type='random'):
    """
    模拟给定移除比例下的级联失效。

    参数:
    removal_ratio (float): 要移除的节点比例（0到1之间）。
    G (networkx.Graph): 要模拟的图。
    attack_type (str): 攻击类型，'random' 或 'degree'。

    返回:
    float: 最大连通子图的比例。
    """
    G_copy = deepcopy(G)  # 创建网络的深拷贝，避免修改原始网络
    if attack_type == 'random':
        nodes_to_remove = random.sample(list(G_copy.nodes()), int(removal_ratio * len(G_copy)))  # 随机选择要移除的节点
    elif attack_type == 'degree':
        nodes_sorted_by_degree = sorted(G_copy.nodes(), key=lambda n: G_copy.degree(n), reverse=True)  # 根据度从高到低排序节点
        nodes_to_remove = nodes_sorted_by_degree[:int(removal_ratio * len(G_copy))]  # 选择度最高的节点进行移除
    else:
        raise ValueError("Unsupported attack type. Choose 'random' or 'degree'.")
    G_copy.remove_nodes_from(nodes_to_remove)  # 从网络中移除选定的节点
    return perform_cascade_failure(G_copy)  # 执行级联失效过程并返回结果
```

**基本思路：**

- 初始化网络：定义每个节点的电压、电流、最大容量等参数。
- 设置初始故障：选择一个节点作为初始故障点。

- 级联故障检测：如果某条线路的电流超过其最大容量，则断开该线路，并重复步骤3，直到没有新的故障发生。
- 终止条件：当所有可能的故障都已经处理完毕，或者系统已经稳定，停止模拟。

**代码1**
代码说明：

- PowerNode类：表示电力网络中的一个节点，包含电压、电流、最大允许电流和状态。
- PowerNetwork类：表示整个电力网络，包含节点和连接关系。calculate_current方法计算每个节点的电流， check_faults方法检查是否有节点过载，propagate_fault方法处理故障传播。
- main函数：初始化节点和连接，设置初始故障，并模拟故障传播过程。

```sh
import numpy as np 
 
class PowerNode:
    def __init__(self, voltage, max_current):
        self.voltage  = voltage  # 节点电压 
        self.current  = 0        # 流经节点的电流 
        self.max_current  = max_current  # 最大允许电流 
        self.status  = 'active'  # 节点状态：active或faulty 
 
class PowerNetwork:
    def __init__(self, nodes, connections):
        self.nodes  = nodes      # 节点列表 
        self.connections  = connections  # 连接关系列表，每条连接由两个节点索引组成 
        self.failed_nodes  = []   # 记录失败的节点 
 
    def calculate_current(self):
        # 计算每个节点的电流 
        for i in range(len(self.nodes)): 
            if self.nodes[i].status  == 'active':
                # 假设电流均匀分配到相邻节点 
                neighbors = [j for j, conn in enumerate(self.connections)  if i in conn]
                num_active_neighbors = sum(1 for j in neighbors if self.nodes[j].status  == 'active')
                if num_active_neighbors > 0:
                    self.nodes[i].current  = self.nodes[i].voltage  / num_active_neighbors 
                else:
                    self.nodes[i].current  = 0 
 
    def check_faults(self):
        # 检查是否有节点过载 
        new_failures = []
        for i in range(len(self.nodes)): 
            if self.nodes[i].status  == 'active' and self.nodes[i].current  > self.nodes[i].max_current: 
                new_failures.append(i) 
        return new_failures 
 
    def propagate_fault(self, faulty_node):
        # 处理故障传播 
        self.nodes[faulty_node].status  = 'faulty'
        self.failed_nodes.append(faulty_node) 
        print(f"Fault occurred at node {faulty_node}")
 
def main():

        new_failures = network.check_faults() 
        if not new_failures:

        for fault in new_failures:
```

## _5.4 网络瓦解算法_

### _5.4.1 BPD算法_

**定义**
BPD启发式网络瓦解算法（Belief Propagation Decimation,BPD）是一种特定的元启发式算法，专门用于处理网络瓦解问题。该算法结合了信念传播（Belief Propagation, BP）技术和逐步削减（Decimation）策略，旨在通过高效地识别网络中的关键节点或边，以最小化网络瓦解的影响。
**BPD算法的主要步骤：**

- 初始化：首先，对网络中的每个节点或边分配初始概率值，这些概率值反映了节点或边在瓦解过程中被移除的可能性。
- 信念传播：利用BP算法在网络中传递信息，更新每个节点或边的概率值。BP算法通过迭代的方式，使每个节点根据其邻居的信息调整自身的概率值，最终达到一个相对稳定的概率分布。
- 逐步削减：根据更新后的概率值，选择概率最高的节点或边进行移除。这一过程称为“削减”（Decimation）。每次削减后，重新执行信念传播步骤，更新剩余网络中的概率值。
- 重复：重复信念传播和逐步削减步骤，直到网络达到预定的瓦解状态或满足特定的停止条件。

**应用场景：**

- 网络瓦解预测：通过BPD算法预测网络中哪些节点或边最有可能成为瓦解的关键点，从而提前采取措施防止网络瓦解。
- 网络瓦解恢复：当网络已经发生部分瓦解时，BPD算法可以帮助快速识别需要优先恢复的节点或边，加速网络的恢复过程。
- 网络瓦解控制：通过动态调整网络结构，控制瓦解的扩散速度和范围，减少对整体网络的影响。

```sh
import numpy as np 
 
class Variable:
    def __init__(self, name, domain):
        self.name  = name 
        self.domain  = domain  # 可能的取值，例如 [0, 1]
        self.factor_nodes  = []  # 连接的因子节点 
        self.messages  = {}  # 消息字典，键为因子节点，值为消息数组 
 
class Factor:
    def __init__(self, variables, function):
        self.variables  = variables  # 连接的变量节点列表 
        self.function  = function  # 因子函数，输入为变量的取值，返回权重 
        self.messages  = {}  # 消息字典，键为变量节点，值为消息数组 
 
def initialize_messages(variables, factors):
    for var in variables:
        for factor in var.factor_nodes: 
            var.messages[factor]  = np.ones(len(var.domain)) 
            factor.messages[var]  = np.ones(len(var.domain)) 
 
def compute_message(sender, receiver):
    if isinstance(sender, Variable):
        # 从变量发送到因子 
        factor = receiver 
        variables = factor.variables  
        other_vars = [v for v in variables if v != sender]
        message = np.zeros(len(sender.domain)) 
        for s_val in range(len(sender.domain)): 
            product = 1.0 
            for var in other_vars:
                product *= var.messages[factor][var.domain.index(s_val)] 
            message[s_val] = product 
        return message 
    else:
        # 从因子发送到变量 
        var = receiver 
        message = np.zeros(len(var.domain)) 
        for val in range(len(var.domain)): 
            product = 1.0 
            for neighbor in var.factor_nodes: 
                product *= neighbor.messages[var][val] 
            message[val] = product 
        return message 
 
def belief_propagation(variables, factors, iterations=10):
    for _ in range(iterations):
        for var in variables:
            for factor in var.factor_nodes: 
                msg = compute_message(var, factor)
                factor.messages[var]  = msg 
        for factor in factors:
            for var in factor.variables: 
                msg = compute_message(factor, var)
                var.messages[factor]  = msg 
 
def decimate_variable(variables):
    max_entropy = -1 
    selected_var = None 
    for var in variables:
        beliefs = np.prod([factor.messages[var]  for factor in var.factor_nodes],  axis=0)
        beliefs /= np.sum(beliefs) 
        entropy = -np.sum(beliefs  * np.log(beliefs  + 1e-10))
        if entropy > max_entropy:
            max_entropy = entropy 
            selected_var = var 
    return selected_var 
 
def solve_coloring():
    # 创建变量 
    variables = [Variable(f'x{i}', [0, 1]) for i in range(4)]
  
    # 创建因子（边）
    factors = []
    edges = [(0,1), (1,2), (2,3), (3,0)]
    for u, v in edges:
        def factor_func(xu, xv):
            return 1.0 if xu != xv else 0.0 
        factor = Factor([variables[u], variables[v]], factor_func)
        factors.append(factor) 
        variables[u].factor_nodes.append(factor) 
        variables[v].factor_nodes.append(factor) 
  
    # 初始化消息 
    initialize_messages(variables, factors)
  
    # 运行信念传播 
    belief_propagation(variables, factors, iterations=5)
  
    # 消去过程 
    assignment = {}
    remaining_vars = variables.copy() 
    while remaining_vars:
        # 选择熵最大的变量 
        var = decimate_variable(remaining_vars)
        # 计算信念 
        beliefs = np.prod([f.messages[var]  for f in var.factor_nodes],  axis=0)
        beliefs /= np.sum(beliefs) 
        # 固定变量 
        value = var.domain[np.argmax(beliefs)] 
        assignment[var.name] = value 
        # 移除该变量 
        remaining_vars.remove(var) 
        # 更新相关因子 
        for factor in var.factor_nodes: 
            factor.variables.remove(var) 
            if len(factor.variables)  == 0:
                factors.remove(factor) 
        # 重新初始化消息 
        initialize_messages(remaining_vars, factors)
        belief_propagation(remaining_vars, factors, iterations=2)
  
    print("变量赋值结果：", assignment)
 
if __name__ == "__main__":
    solve_coloring()
```

### _5.4.2 CI算法_

**定义**
CI（Collective Influence）算法是一种基于中心性指标的网络瓦解策略，主要用于识别网络中对整体结构稳定性影响最大的节点。该算法结合了节点的度中心性和介数中心性，但更侧重于节点及其邻居节点的影响范围，从而有效地识别出那些在局部和全局层面上都具有重要影响力的节点。

**主要步骤**

- 首先计算每个节点的度中心性，即节点直接连接的邻居数量。度中心性高的节点在网络中拥有较多的直接联系，可能在网络中占据重要位置。
- 邻居节点的影响：CI算法不仅考虑节点本身的度中心性，还考虑其邻居节点的度中心性。
- 选择关键节点：根据计算得到的CI值，选择CI值最高的节点作为关键节点。这些节点在网络中具有较高的集体影响力，移除它们可以有效地破坏网络的连通性。
- 迭代过程：移除选定的关键节点后，重新计算剩余节点的CI值，重复上述步骤，直到网络被瓦解到一定程度或满足预定条件。

**应用场景**
CI算法广泛应用于社交网络、生物网络、交通网络等领域，用于识别网络中的关键节点，以提高网络的安全性和鲁棒性。在我们日常社交网络中，CI算法可以帮助识别出最具影响力的用户，以便采取措施防止信息的恶意传播。

**代码学习**

**1.问题描述**
在社交网络中，选择影响力最大的用户对于信息传播至关重要。CI算法结合了度中心性和介数中心性，帮助识别关键节点。
**2.思路**

- 构建图结构：使用NetworkX读取边列表，构建图。
- 计算度中心性：度中心性衡量节点的连接数量。
- 计算介数中心性：介数中心性衡量节点在信息传递中的中介作用。
- 计算CI得分：将度中心性和介数中心性相乘，得到CI得分。
- 选择前k个节点：根据CI得分排序，选择得分最高的k个节点。

**3.代码**

```sh
import networkx as nx
 
def collective_influence(G, r=3):
    """
    计算网络中每个节点的集体影响力
    :param G: NetworkX图
    :param r: 邻域半径
    :return: 节点及其集体影响力值的字典
    """
    ci_values = {}
  
    for node in G.nodes(): 
        k_v = G.degree(node) 
        if k_v == 1:
            ci_values[node] = 0
            continue
      
        ball = nx.ego_graph(G,  node, radius=r)
        sum_k_u = sum(G.degree(u)  - 1 for u in ball.nodes()  if u != node)
        ci_values[node] = (k_v - 1) * sum_k_u
  
    return ci_values
 
def find_top_influential_nodes(G, num_nodes, r=3):
    """
    找出网络中最重要的num_nodes个节点 
    :param G: NetworkX图
    :param num_nodes: 需要找的节点数量 
    :param r: 邻域半径 
    :return: 最重要的节点列表
    """
    influential_nodes = []
    for _ in range(num_nodes):
        ci_values = collective_influence(G, r)
        max_ci_node = max(ci_values, key=ci_values.get) 
        influential_nodes.append(max_ci_node) 
        G.remove_node(max_ci_node) 
  
    return influential_nodes 
 
# 示例网络 
G = nx.barabasi_albert_graph(100,  5)
 
# 找出最重要的5个节点
top_nodes = find_top_influential_nodes(G, 5)
print("最重要的5个节点:", top_nodes)
```

### _5.4.3 FINDER算法_

**定义**
FINDER (FInding key players in complex Networks through DEep Reinforcement learning) 是一种基于深度强化学习的算法，旨在识别复杂网络中的关键节点。这些关键节点的移除能够最大限度地改变网络的连通性，从而实现网络的“瓦解”或优化。

**训练与应用**
(1)离线训练:
在模拟的小规模网络（如 BA 无标度网络）中进行离线训练，通过穷举法找到最优解。
训练过程中，智能体学会如何在不同网络结构下选择最优节点进行移除。

(2)在线应用:
在真实场景下的网络中，使用训练好的智能体，根据当前网络状态决定移除哪个节点。
通过不断迭代，逐步优化网络连通性，实现网络的瓦解或优化。

**性能测试:**
在 BA、ER 和 WS 模型生成的随机网络上进行评估，FINDER 在 BA 模型生成的测试集中表现最佳。
与传统方法相比，FINDER 在节点数较多的网络中显示出显著的性能优势。

**应用场景：**

- 网络免疫: 通过移除关键节点，减少疾病的传播。
- 疫情控制: 识别超级传播者，有效控制疫情扩散。
- 药物设计: 找到蛋白质相互作用网络的关键节点，指导药物靶点选择。

### _5.4.4 禁忌搜索算法_

**定义**
禁忌搜索算法是一种元启发式优化算法，主要用于解决组合优化问题。它的核心思想是通过维护一个禁忌列表来避免搜索过程陷入局部最优解，从而实现全局最优解的寻找。

> 关于资料图5-18 基于禁忌搜索的网络瓦解策略示意图的理解：
> 测度指标：网络中的相对最大连通片规模
> 关注：规模变化量越大，说明瓦解效果越好
> 在每一轮迭代时，既需要明确是以上一轮最优瓦解效果的解作为新一轮的初始，同时也要记得排除之前已经搜索过的解（写在下方）。
> 在完成迭代时，如果得到的解不是更优，需要从之前的解中寻找是否存在更优解。

**禁忌搜索算法的主要步骤：**

- 1.初始化：随机生成一个初始解，并将其作为当前解。
- 2.邻域搜索：对当前解进行邻域搜索，生成与当前解相邻的解。
- 3.选择：从邻域中选择一个最优解作为下一步的当前解。
- 4.更新禁忌列表：将当前解加入禁忌列表中，记录搜索过程中不能选择的解。
- 5.剪枝：从邻域中剪去禁忌列表中的解。
- 6.终止条件判断：如果满足终止条件（如达到最大迭代次数或满足目标函数阈值），则算法结束；否则返回步骤2。

**关键概念：**

- 邻域：定义了搜索空间，通常是通过变换当前解的某些部分来生成。
- 禁忌列表：记录最近搜索过的一些解，以避免重复探索。
- 禁忌长度：决定某个解在禁忌列表中停留的时间。
- 特赦准则：允许在特定条件下打破禁忌，选择看似劣质但可能带来更好结果的解决方案。

**应用场景：**
1.组合优化问题

- 指派问题：在指派优化问题中，禁忌搜索算法用于寻找最优的任务分配方案，使得总体的执行成本或效益最大化1.
- 旅行商问题（TSP）：寻找最短路径，使旅行商经过所有城市并返回起点，路径长度最小化。
- 背包问题：在有限的容量下，选择物品以最大化总价值。

2.生产调度

- 车间调度：优化生产线上的任务安排，减少生产时间和成本。
- 资源分配：在多个项目中合理分配有限的资源，以最大化整体效益。

3.机器学习

- 特征选择：从大量特征中选择最相关的特征，以提高模型的性能和解释性。
- 神经网络优化：优化神经网络的结构和参数，以提高预测准确性。

**用禁忌搜索算法解决旅行商问题（TSP）**
旅行商问题（Traveling Salesman Problem, TSP）是一个经典的组合优化问题，目标是在给定一组城市和它们之间的距离的情况下，找到一条最短的回路，使得旅行商能够访问每个城市恰好一次并返回起点。

```sh
import random 
import math 
 
# 定义城市坐标 
cities = [(0, 0), (1, 2), (3, 1), (4, 3), (2, 4)]  # 示例城市坐标 
 
def calculate_distance(path):
    """计算路径的总距离"""
    total_distance = 0 
    for i in range(len(path)):
        x1, y1 = cities[path[i]]
        x2, y2 = cities[path[(i+1) % len(path)]]
        distance = math.sqrt((x2  - x1)**2 + (y2 - y1)**2)
        total_distance += distance 
    return total_distance 
 
def generate_initial_solution():
    """生成初始解"""
    path = list(range(len(cities)))
    random.shuffle(path) 
    return path 
 
def main():
    max_iterations = 1000  # 最大迭代次数 
    tabu_length = 20       # 禁忌表长度 
    current_path = generate_initial_solution()
    best_path = current_path.copy() 
    best_distance = calculate_distance(best_path)
    tabu_list = []
 
    for _ in range(max_iterations):
        neighbors = []
        n = len(current_path)
        # 生成所有可能的邻域解（两两交换）
        for i in range(n):
            for j in range(i+1, n):
                new_path = current_path.copy() 
                new_path[i], new_path[j] = new_path[j], new_path[i]
                neighbors.append(new_path) 
      
        # 找出不在禁忌表中的最优解 
        best_neighbor = None 
        best_neighbor_distance = float('inf')
        for neighbor in neighbors:
            if tuple(neighbor) not in tabu_list:
                dist = calculate_distance(neighbor)
                if dist < best_neighbor_distance:
                    best_neighbor = neighbor 
                    best_neighbor_distance = dist 
      
        # 如果没有找到更好的解，随机选择一个不在禁忌表中的解 
        if best_neighbor is None:
            for neighbor in neighbors:
                if tuple(neighbor) not in tabu_list:
                    best_neighbor = neighbor 
                    best_neighbor_distance = calculate_distance(neighbor)
                    break 
      
        # 更新当前解和最佳解 
        current_path = best_neighbor.copy() 
        current_distance = best_neighbor_distance 
        if current_distance < best_distance:
            best_distance = current_distance 
            best_path = current_path.copy() 
      
        # 更新禁忌表 
        tabu_list.append(tuple(current_path)) 
        if len(tabu_list) > tabu_length:
            tabu_list.pop(0) 
  
    print("Best path:", best_path)
    print("Best distance:", best_distance)
 
if __name__ == "__main__":
    main()
```
