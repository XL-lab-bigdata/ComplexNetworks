# 第三章 网络模型

## 3.1 规则网络

规则网络是网络模型中最基础的类型之一，它的特点是所有节点的度数相同，这种均匀性使得规则网络在分析时相对简单。

### 3.1.1 全耦合网络

全耦合网络是规则网络的一个极端形式，在这种网络中，每个节点都与其他所有节点相连。这种网络的结构让我想起了一个小型的团队，每个成员都与其他所有成员保持联系。在实际应用中，全耦合网络可以用来模拟高度协作的团队或系统。

**拓扑特征：**

**度分布**：所有节点的度数相同，度分布为Delta分布。

**平均路径长度**：非常短，信息传播速度快。

**集聚系数**：非常高，网络的局部聚集性很强。

我使用`complete_graph(n)`函数构建了一个包含10个节点的全耦合网络，代码如下：

```python
# 创建一个10个节点的完全图
G_complete = nx.complete_graph(10)

# 绘制图形
nx.draw(G_complete, with_labels=True, node_color='skyblue', node_size=800, font_size=10)

# 显示图形
plt.show()
import networkx as nx

G_nearest_neighbor = nx.watts_strogatz_graph(n=10, k=4, p=0)
```

### 3.1.2 最近邻耦合网络

最近邻耦合网络让我联想到我们日常生活中的邻里关系。在这种网络中，每个节点只与其最近的几个邻居相连。这种结构在社交网络中非常常见，因为人们通常与身边的人建立联系。

**拓扑特征：**

**度分布**：所有节点的度数相同，度分布为Delta分布。

**平均路径长度**：较长，信息传播速度较慢。

**集聚系数**：较高，网络的局部聚集性较强。

我用`watts_strogatz_graph(n, k, p)`函数构建了一个包含10个节点、每个节点与其4个最近邻节点相连的网络，代码如下：

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建最近邻耦合网络
G_nearest_neighbor = nx.watts_strogatz_graph(n=10, k=4, p=0)

# 查看图的基本信息
print("节点数量:", G_nearest_neighbor.number_of_nodes())
print("边的数量:", G_nearest_neighbor.number_of_edges())

# 可视化图
nx.draw(G_nearest_neighbor, with_labels=True, node_color='lightblue', node_size=800, font_size=12)
plt.title("Nearest Neighbor Coupled Network")
plt.show()
```

## 3.2 随机网络

随机网络模型的引入，让我意识到网络的连接方式并不总是固定的，随机性在复杂网络中扮演着重要角色，因此研究一下ER随机网络模型。

### 3.2.1 具有固定连边概率的ER随机网络

在具有固定连边概率的ER随机网络中，每条边存在的概率是固定的。这就像是在一个社交场合中，每个人之间是否成为朋友都有一定的概率。我用`erdos_renyi_graph(n, p)`函数构建了一个包含10个节点、固定连边概率为0.5的ER随机网络。

```python
import networkx as nx
import matplotlib.pyplot as plt

# 创建 Erdős - Rényi 随机图
G_er_p = nx.erdos_renyi_graph(n=10, p=0.5)

# 查看图的基本信息
print("节点数量:", G_er_p.number_of_nodes())
print("边的数量:", G_er_p.number_of_edges())

# 可视化图
nx.draw(G_er_p, with_labels=True, node_color='lightgreen', node_size=800, font_size=12)
plt.title("Erdős - Rényi Random Graph (n=10, p=0.5)")
plt.show()
```

**拓扑特征：**

**度分布**：泊松分布，节点的度数围绕平均值波动。

**平均路径长度**：较短，信息传播速度快。

**集聚系数**：较低，网络的局部聚集性较弱。

### 3.2.2 具有固定边数的ER随机网络

我进一步探索了具有固定边数的ER随机网络。通过计算连边概率`P=2M/(N(N-1))`，我构建了一个包含10个节点、固定边数为20的ER随机网络，这种网络模型在描述边数固定的随机网络系统时非常有用。代码如下：

```python
import networkx as nx
import matplotlib.pyplot as plt

# 设定节点和边的数量
N = 10
M = 20
# 计算连边概率
P = M * 2 / (N * (N - 1))

# 生成 ER 随机图
G_er_m = nx.erdos_renyi_graph(N, P)

# 查看图的基本信息
print("节点数量:", G_er_m.number_of_nodes())
print("实际边的数量:", G_er_m.number_of_edges())
print("期望边的数量:", M)

# 可视化图
nx.draw(G_er_m, with_labels=True, node_color='lightgreen', node_size=800, font_size=12)
plt.title(f"Erdős - Rényi Random Graph (N={N}, M={M})")
plt.show()
```

### 3.2.3 随机网络的拓扑性质

在深入研究ER随机网络的过程中，我特别关注了其拓扑性质，这些性质不仅揭示了随机网络的基本特征，还帮助我理解了随机性如何影响网络的整体结构和功能。

**平均度**

在ER随机网络中，每个节点的平均度数为`p(N-1)`，其中`p`是连边概率，`N`是节点总数。这意味着，如果连边概率`p`较高，每个节点平均会连接到更多的其他节点。我通过模拟不同规模和连边概率的网络，观察到平均度的变化，这让我对网络的密集程度有了更直观的认识。

**度分布**

度分布是描述网络中节点连接数分布的重要指标。在ER随机网络中，当网络规模较大且连边概率较小时，度分布近似为泊松分布。这意味着大多数节点的度数接近平均值，但也会有一些节点的度数明显高于或低于平均值。通过绘制度分布图，我看到了这种分布的形状，并理解了它如何随着`p`和`N`的变化而变化。

**集聚系数**

集聚系数反映了网络中节点的局部聚集性。在ER随机网络中，两个节点之间的连边概率无论是否具有共同邻居节点，均为`p`。因此，网络的集聚系数为`p`。这表明，随机网络的局部聚集性相对较低，因为每个节点与其他节点的连接是随机的，而不是基于局部结构。

**平均路径长度**

平均路径长度是衡量网络中信息传播速度的关键指标。在ER随机网络中，平均路径长度与网络规模的对数成正比，即`L ~ ln(N) / ln(k)`，其中`k`是平均度。这意味着，尽管网络规模可能很大，但平均路径长度相对较短，信息可以在网络中快速传播。我通过模拟不同规模的网络，计算了平均路径长度，并验证了这一关系。

**最大连通片**

在ER随机网络中，存在一个临界点`p_c`，当`p > p_c`时，网络中会出现一个巨大的连通片，包含大部分节点。这个现象让我对网络的连通性有了更深入的理解。通过模拟不同连边概率的网络，我观察到了最大连通片的形成过程，并理解了临界点`p_c`的意义。

通过这些研究，我不仅对ER随机网络的拓扑性质有了更深入的理解，还学会了如何通过模拟和分析来验证这些性质。这些知识将帮助我在未来的研究中更好地理解和应用随机网络模型。

## 3.3 小世界网络

小世界网络模型结合了规则网络和随机网络的特点，具有较短的平均路径长度和较高的集聚系数，这种网络模型更贴近现实中的社交网络和交通网络。

### 3.3.1 WS小世界网络

我用`watts_strogatz_graph(n, k, p)`函数构建了一个包含1000个节点、平均度为6、重连边概率为0.2的WS小世界网络，代码如下：

```python
import networkx as nx
import matplotlib.pyplot as plt

WS = nx.watts_strogatz_graph(1000, 6, 0.2)

print("节点数量:", WS.number_of_nodes())
print("边的数量:", WS.number_of_edges())

if nx.is_connected(WS):
    avg_path_length = nx.average_shortest_path_length(WS)
    print("平均路径长度:", avg_path_length)
else:
    print("图不是连通的，无法计算平均路径长度。")

clustering_coefficient = nx.average_clustering(WS)
print("平均聚类系数:", clustering_coefficient)

pos = nx.circular_layout(WS)
nx.draw_networkx_nodes(WS, pos, node_size=2, node_color='lightblue')
nx.draw_networkx_edges(WS, pos, edge_color='gray')

plt.axis('off')

plt.title("Watts - Strogatz Small - World Graph")

plt.show()
```

在学习这个模型的过程中，我尝试了不同的节点数量、平均度和重连边概率，观察网络结构的变化。我发现，当`p`值较小时，网络的集聚系数较高，但平均路径长度较长；而当`p`值较大时，网络的平均路径长度显著缩短，但集聚系数下降。这让我意识到，这种网络模型在描述具有短路径和高集聚系数的系统时非常有用，例如在社交网络和交通网络中。

**集聚系数**：较高，网络的局部聚集性较强。

### 3.3.2 NW小世界网络

在研究小世界网络模型时，我特别关注了NW小世界网络。这个模型由Newman和Watts提出，旨在解决WS小世界网络模型中可能出现的孤立子图问题。NW小世界网络通过在规则网络的基础上随机添加少量连边来减少平均路径长度，同时保持较高的集聚系数。

**模型构建**

NW小世界网络的构建过程如下：

1. 初始化一个包含N个节点的最近邻耦合网络。
2. 以连边概率p在Nk/2对节点之间随机添加连边，确保不产生重复和自连接。

这种随机化加边机制在保留规则网络局部连接特性的基础上，通过随机化加边的方式引入了随机性。我使用`newman_watts_strogatz_graph(n, k, p)`函数来构建NW小世界网络。例如，构建一个包含1000个节点、平均度为6、随机加边概率为0.2的NW小世界网络，代码如下：

```python
import networkx as nx
import matplotlib.pyplot as plt

# NW network
# 生成 NW 小世界网络，有 1000 个节点，每个节点初始有 6 个邻居，添加新边概率为 0.2
NW = nx.newman_watts_strogatz_graph(1000, 6, 0.2)

# 查看图的基本信息
print("节点数量:", NW.number_of_nodes())
print("边的数量:", NW.number_of_edges())

# 计算图的平均路径长度和聚类系数
if nx.is_connected(NW):
    avg_path_length = nx.average_shortest_path_length(NW)
    print("平均路径长度:", avg_path_length)
else:
    print("图不是连通的，无法计算平均路径长度。")

# 计算聚类系数
clustering_coefficient = nx.average_clustering(NW)
print("平均聚类系数:", clustering_coefficient)

pos = nx.circular_layout(NW)
nx.draw_networkx_nodes(NW, pos, node_size=2, node_color='lightgreen')
nx.draw_networkx_edges(NW, pos, edge_color='gray')

# 隐藏坐标轴
plt.axis('off')

plt.title("Newman - Watts - Strogatz Small - World Graph")

# 显示图形
plt.show()
```

运行结果：

**拓扑性质**

NW小世界网络的拓扑性质非常有趣，它结合了规则网络的高集聚系数和随机网络的短平均路径长度。

**度分布**：度分布接近泊松分布，但存在一些长程连接，这些连接显著减少了平均路径长度。

**平均路径长度**：较短，信息传播速度快。这是因为随机添加的长程边为信息传播提供了捷径。

**集聚系数**：较高，网络的局部聚集性较强。这是因为规则网络的局部连接特性被保留下来。

通过调整随机加边概率p，可以控制网络的随机程度。当p较小时，网络接近规则网络；当p较大时，网络接近随机网络，这种灵活性使得NW小世界网络在模拟现实世界中的社交网络和交通网络时非常有用。

## 3.4 无标度网络

无标度网络的度分布呈现幂律分布特征，少数节点的度数远高于平均值。这种网络模型更贴近现实中的复杂网络，如互联网、科研合作网络和蛋白质交互网络等，从而需要深入研究BA无标度网络和Price无标度网络。

### 3.4.1 BA无标度网络

BA无标度网络由Barabasi和Albert于1999年提出，通过引入“增长”和“优先连接”机制生成。增长机制指网络在演化过程中节点和边不断增加，优先连接机制指新节点更倾向于连接到已有度较高的节点。这种网络模型的度分布呈现幂律分布，平均路径长度较短，集聚系数较低，我意识到，这种网络模型在描述具有幂律分布特征的复杂网络系统时十分关键。

**拓扑特征：**

**度分布**：幂律分布，少数节点的度数远高于平均值。

**平均路径长度**：较短，信息传播速度快。

**集聚系数**：较低，网络的局部聚集性较弱。

我用`barabasi_albert_graph(n, m, m0)`函数构建了一个包含500个节点、新增节点平均度为3的BA无标度网络，代码如下

```python
import networkx as nx
import matplotlib.pyplot as plt

# 生成 BA 无标度网络
G_ba = nx.barabasi_albert_graph(n=500, m=3)

# 查看图的基本信息
print("节点数量:", G_ba.number_of_nodes())
print("边的数量:", G_ba.number_of_edges())

# 可视化图
pos = nx.spring_layout(G_ba)
nx.draw(G_ba, pos, node_size=[d * 10 for d in dict(G_ba.degree()).values()], node_color='lightblue', with_labels=False)
plt.title("Barabási - Albert Scale - Free Network")
plt.show()
```

### 3.4.2 Price无标度网络

Price无标度网络用于描述学术引文网络的结构。这种网络体现了“累积优势”特征，即“富者愈富”的现象。在学术界，那些已经被广泛引用的论文更容易获得更多的引用。这种网络模型的度分布也呈现幂律分布，适用于描述学术引文网络等具有累积优势特征的系统。

**拓扑特征：**

**度分布**：幂律分布，少数节点的度数远高于平均值。

**平均路径长度**：较短，信息传播速度快。

**集聚系数**：较低，网络的局部聚集性较弱。

我通过自定义函数来生成Price无标度网络，代码如下：

```python
import networkx as nx
import random
import matplotlib.pyplot as plt

def price_model(n, m):
    G = nx.DiGraph()
    G.add_nodes_from(range(m))
    for i in range(m, n):
        G.add_node(i)
        targets = _select_targets(G, m)
        for t in targets:
            G.add_edge(i, t)
    return G

def _select_targets(G, m):
    targets = set()
    nodes = list(G.nodes())
    in_degrees = [G.in_degree(node) + 1 for node in nodes]
    total_in_degrees = sum(in_degrees)
    probabilities = [in_degree / total_in_degrees for in_degree in in_degrees]
    while len(targets) < m:
        node = random.choices(nodes, weights=probabilities, k=1)[0]
        targets.add(node)
    return targets

# 设置模型参数

m = 3
```

### 3.5.1 BBV加权网络

BBV加权网络通过引入边的权重，刻画节点间的强度关系。这种网络模型引入增长机制和权重强化机制，动态刻画节点和边的权重变化，在实际应用中，BBV加权网络适用于描述具有权重差异的复杂网络系统，如城市交通网络。**此外，p29页所说的如图3-19所示似乎标错了，应该是如图3-18所示。**

**拓扑特征：**

**度分布**：幂律分布，少数节点的度数远高于平均值。

**边权重分布**：幂律分布，少数边的权重远高于平均值。

**平均路径长度**：较短，信息传播速度快。

**集聚系数**：较低，网络的局部聚集性较弱。

通过自定义函数来生成BBV加权网络，代码如下：

```python
import networkx as nx
import numpy as np
import matplotlib.pyplot as plt

def bbv_model(n, m, beta):
    G = nx.complete_graph(m)
    nx.set_edge_attributes(G, 1, 'weight')
    for i in range(m, n):
        targets = _select_targets(G, m)
        G.add_node(i)
        for t in targets:
            G.add_edge(i, t, weight=1)
            _update_weights(G, i, t, beta)
    return G

def _select_targets(G, m):
    targets = set()
    probabilities = _compute_attachment_probabilities(G)
    while len(targets) < m:
        node = np.random.choice(list(G.nodes()), p=probabilities)
        targets.add(node)
    return targets

def _compute_attachment_probabilities(G):
    total_strength = sum(G.degree(node, weight='weight') for node in G.nodes())
    if total_strength == 0:
        return [1.0 / len(G.nodes())] * len(G.nodes())  # 如果总强度为零，返回均匀概率
    probabilities = []
    for node in G.nodes():
        degree_weight = G.degree(node, weight='weight')
        probability = degree_weight / total_strength
        probabilities.append(probability)
    # 检查概率列表中是否有NaN值，并替换为均匀概率
    if any(np.isnan(probabilities)):
        probabilities = [1.0 / len(G.nodes())] * len(G.nodes())
    return probabilities

def _update_weights(G, i, t, beta):
    for node in [i, t] + list(G.neighbors(t)):
        G[i][t]['weight'] += beta * G.degree(node, weight='weight')

# 设置模型参数
n = 100  # 节点总数
m = 3    # 每个新节点连接的目标节点数量
beta = 0.5  # 权重因子

# 生成BBV模型网络
G_bbv = bbv_model(n, m, beta)

# 绘制网络
plt.figure(figsize=(12, 8))
pos = nx.spring_layout(G_bbv)  # 使用弹簧布局
edges = G_bbv.edges(data=True)
weights = [edge[2]['weight'] for edge in edges]
nx.draw(G_bbv, pos, node_size=50, node_color='lightblue', edge_color=weights, edge_cmap=plt.cm.Blues, with_labels=False)
plt.title("BBV加权网络示例")
plt.show()

# 绘制节点度分布
degrees = [d for n, d in G_bbv.degree()]
plt.figure(figsize=(10, 6))
plt.hist(degrees, bins=range(max(degrees)+1), alpha=0.7, color='blue', edgecolor='black')
plt.title("节点度分布")
plt.xlabel("度")
plt.ylabel("节点数量")
plt.show()

# 绘制边权重分布
weights = [G_bbv[u][v]['weight'] for u, v in G_bbv.edges()]
plt.figure(figsize=(10, 6))
plt.hist(weights, bins=range(int(max(weights))+1), alpha=0.7, color='green', edgecolor='black')
plt.title("边权重分布")
plt.xlabel("权重")
plt.ylabel("边数量")
plt.show()
```

### 3.5.2 DHN确定性层次网络

DHN确定性层次网络专注于网络的层次结构，适用于分析具有分层特征的系统。这种网络模型从一个包含m个节点的全耦合网络开始，通过复制初始网络结构和扩展模块机制生成。在实际应用中，DHN确定性层次网络适用于描述具有层次结构的复杂网络系统，如组织结构或模块化网络。

**拓扑特征：**

**度分布**：幂律分布，少数节点的度数远高于平均值。

**平均路径长度**：较短，信息传播速度快。

**集聚系数**：较高，网络的局部聚集性较强。

我通过自定义函数来生成DHN确定性层次网络，代码如下：

```python
import networkx as nx
import matplotlib.pyplot as plt

def generate_dhn(m, k, num_layers, total_nodes):
    G = nx.DiGraph()
    initial_module = list(range(1, m + 1))
    G.add_nodes_from(initial_module)
    G.add_edges_from((0, node) for node in initial_module)
    current_layer_nodes = initial_module[:]
    current_layer_size = m
    for layer in range(1, num_layers + 1):
        next_layer_nodes = []
        for base_node in current_layer_nodes:
            for copy_id in range(k):
                new_nodes = [base_node + copy_id * current_layer_size + i for i in range(1, m + 1)]
                G.add_nodes_from(new_nodes)
                next_layer_nodes.extend(new_nodes)
                G.add_edges_from((base_node, new_node) for new_node in new_nodes)
        current_layer_nodes = next_layer_nodes
        current_layer_size *= k
    return G.subgraph(range(total_nodes)).copy()

m_dhn = 5
k_dhn = 3
num_layers_dhn = 4
n_dhn = 1600

dhn_network = generate_dhn(m_dhn, k_dhn, num_layers_dhn, n_dhn)

# 查看图的基本信息
print("节点数量:", dhn_network.number_of_nodes())
print("边的数量:", dhn_network.number_of_edges())

# 可视化图
pos = nx.spring_layout(dhn_network)
nx.draw(dhn_network, pos, node_size=30, node_color='lightblue', with_labels=False, arrows=True)
plt.title("Directed Hierarchical Network")
plt.show()
```

### 3.5.3 KOSKK社会网络

KOSKK社会网络模型专注于社交网络中的动态关系和群体行为，这种网络模型整合了循环闭合、焦点闭合和节点删除机制，同时引入连边权重的动态变化，在实际应用中，KOSKK社会网络通常适用于描述社交网络中的动态关系和群体行为。

**拓扑特征：**

**度分布**：通常呈现偏斜分布，少数节点的度数较高。

**平均路径长度**：较短，信息传播速度快。

**集聚系数**：较高，网络的局部聚集性较强，反映了社交网络中群体行为的紧密性。

我通过自定义函数来生成KOSKK社会网络，代码如下：

```python
import networkx as nx
import numpy as np
import random
from random import choice
from tqdm import tqdm
import matplotlib.pyplot as plt

def local_attachment(G, W, i, theta, p3):
    we = 1
    i_neighbors = list(G.neighbors(i))
    if len(i_neighbors) != 0:
        A = np.array(nx.adjacency_matrix(G).todense())
        wi = W[i]
        sum_wi = np.sum(wi)
        rndPoint = random.uniform(0, sum_wi)
        accumulator = 0.0
        for j, val in enumerate(wi):
            accumulator += val
            if accumulator >= rndPoint:
                j_neighbors = list(G[j])
                if i in j_neighbors:
                    j_neighbors.remove(i)
                if len(j_neighbors) != 0:
                    wj = W[j]
                    w_mid = wj[i]
                    wj[i] = 0
                    sum_wj = np.sum(wj)
                    rndPoint1 = random.uniform(0, sum_wj)
                    accumulator1 = 0.0
                    for k, val1 in enumerate(wj):
                        accumulator1 += val1
                        if accumulator1 > rndPoint1:
                            if A[i, k] == 0:
                                p3_rand = random.random()
                                if p3 > p3_rand:
                                    A[i, k] = 1
                                    A[k, i] = 1
                                    G.add_edge(i, k)
                                    G.add_edge(k, i)
                                    W[i, k] = we
                                    W[k, i] = we
                            W[i, j] = w_mid + theta
                            W[j, i] = w_mid + theta
                            W[j, k] += theta
                            W[k, j] += theta
                            break
                break
    return G, W

def global_attachment(G, W, i, pr):
    we = 1
    i_neighbors = list(G.neighbors(i))
    A = np.array(nx.adjacency_matrix(G).todense())
    if len(i_neighbors) == 0:
        pr = 1
    nodes_list = list(G.nodes)
    nodes_list.remove(i)
    for ij in i_neighbors:
        nodes_list.remove(ij)
    l = choice(nodes_list)
    pr_rand = random.random()
    if pr >= pr_rand:
        A[i, l] = 1
        A[l, i] = 1
        G.add_edge(i, l)
        G.add_edge(l, i)
        W[i, l] += we
        W[l, i] += we
    return G, W

def node_deletion(G, W, i, pd):
    pd_rand = random.random()
    A = np.array(nx.adjacency_matrix(G).todense())
    i_neighbors = list(G.neighbors(i))
    if pd >= pd_rand:
        G.remove_node(i)
        for i1 in i_neighbors:
            A[i, i1] = 0
            A[i1, i] = 0
            W[i, i1] = 0
            W[i1, i] = 0
        G.add_node(i)
    return G, W

def koskk_model(n, theta):
    N = list(range(n))
    pr = 0.0005
    pd = 0.001
    p3 = 0.15
    G = nx.Graph()
    G.add_nodes_from(N)
    W = np.zeros((n, n))
    T = 100000
    for t in range(T):
        nodes_list = list(G.nodes)
        i = choice(nodes_list)
        G, W = global_attachment(G, W, i, pr)
        G, W = local_attachment(G, W, i, theta, p3)
        G1 = G.copy()
        G1.remove_nodes_from(list(nx.isolates(G)))
        nodes_list1 = list(G1.nodes)
        if nodes_list1:
            ii = choice(nodes_list1)
            G, W = node_deletion(G, W, ii, pd)
    return G, W

n = 1000
theta = 0.5
G_koskk, W_koskk = koskk_model(n, theta)

# 查看图的基本信息
print("节点数量:", G_koskk.number_of_nodes())
print("边的数量:", G_koskk.number_of_edges())

# 可视化图
pos = nx.spring_layout(G_koskk)
nx.draw(G_koskk, pos, node_size=30, node_color='lightblue', with_labels=False)
plt.title("KOSKK Social Network")
plt.show()
```
