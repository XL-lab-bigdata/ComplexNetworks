## 1. 节点中心性指标

### 1.1 度中心性（Degree Centrality）

**定义**：与节点直接相连的边总数

- **无向网络**：
  \[ k_i = \sum_{j=1}^{N} a_{ij} \]
- **有向网络**：
  入度：\[ k_i^{in} = \sum_{j=1}^{N} a_{ji} \]
  出度：\[ k_i^{out} = \sum_{j=1}^{N} a_{ij} \]
- **归一化**：\[ DC(i) = \frac{k_i}{N-1} \]
  **特点**：计算简单，仅反映直接影响力。

---

### 1.2 接近中心性（Closeness Centrality）

**定义**：节点到其他节点平均距离的倒数
\[ CC(i) = \frac{N-1}{\sum_{j \neq i} d_{ij}} \]
**应用**：识别网络拓扑几何中心（如图2-2）。

---

### 1.3 介数中心性（Betweenness Centrality）

**定义**：经过节点的最短路径占比\[ BC(i) = \sum_{s \neq t \neq i} \frac{g_{st}(i)}{g_{st}} \]**Brandes算法**：

- 时间复杂度：无权网络 \( O(nm) \)，加权网络 \( O(nm + n^2 \log n) \)
- 流程：广度优先搜索计算最短路径依赖值（表2-1）。

---

### 1.4 子图中心性（Subgraph Centrality）

**定义**：节点参与回路的加权和
\[ SC(i) = \sum_{t=1}^{\infty} \frac{a_{ii}^t}{t!} \]
**特点**：区分度高，计算复杂度高（图2-6）。

---

### 1.5 k-核（k-core）

**定义**：节点在k-壳分解中的最大核数**分解过程**：

1. 删除度<k的节点
2. 递归直至稳定
   **应用**：识别意见领袖（图2-7）。

---

### 1.6 特征向量中心性（Eigenvector Centrality）

**定义**：邻居节点重要性的加权和
\[ EC(i) = c \sum_{j=1}^{N} a_{ij} x_j \]
**局限性**：有向网络中可能失效（图2-8）。

---

### 1.7 Katz中心性

**改进**：引入偏差项β解决有向网络问题
\[ KC(i) = \alpha \sum_{j=1}^{N} a_{ij} x_j + \beta \]
**收敛条件**：\[ \alpha < 1/\lambda_{\text{max}} \]

---

### 1.8 PageRank

**核心思想**：基于随机游走和跳转概率
\[ PR(i) = \frac{1-p}{N} + p \sum_{j \in \Gamma(i)} \frac{PR(j)}{k_j^{out}} \]
**应用**：Google网页排序（图2-9）。

---

### 1.9 LeaderRank

**改进**：添加背景节点
\[ LR_i(t) = \sum_{j=1}^{n+1} \frac{a_{ij}}{k_j} LR_j(t-1) \]
**优势**：收敛快，影响力识别更准（图2-10）。

---

### 1.10 HITS算法

**双指标**：

- **权威值**：\[ x_i = \sum_{j} a_{ij} y_j \]
- **枢纽值**：\[ y_i = \sum_{j} a_{ij} x_j \]
  **应用**：识别信息传播者（图2-11）。

## 2. 网络拓扑结构指标

### 2.1 连通度

- **割点/割边**：删除后增加连通片数量（图2-12）
- **连通度**：最小顶点割集大小
- **边连通度**：最小边割集大小

---

### 2.2 最大连通片（GCC）

**定义**：节点数最多的连通子图（图2-13）**有向网络分类**：

- 强连通片（SCC）
- 弱连通片（WCC）
- 入部（\( G_{IN} \)）、出部（\( G_{OUT} \)）、卷须（\( G_{Tendrils} \)）（图2-14）

---

### 2.3 度分布

**常见类型**：

1. **泊松分布**：\[ p(k) = e^{-\langle k \rangle} \frac{\langle k \rangle^k}{k!} \]（图2-15）
2. **幂律分布**：\[ p(k) \sim k^{-\gamma} \]（图2-16）
   **估计方法**：Logarithmic binning（图2-18, 2-19）

---

### 2.4 度相关性

- **联合概率分布**：\[ P(j,k) = \frac{m(j,k)\mu(j,k)}{2M} \]
- **余平均度**：\[ \langle k_{nn} \rangle(k) = \sum_{k'} k' P_c(k'|k) \]
- **同配系数**：Pearson相关系数（表2-2）

---

### 2.5 集聚系数

**定义**：邻居间实际边数与最大可能边数之比
\[ C_i = \frac{2E_i}{k_i(k_i-1)} \]
**全局指标**：\[ C = \frac{1}{N} \sum_{i=1}^{N} C_i \]（表2-3）

---

### 2.6 平均路径长度与网络效率

- **平均路径长度**：\[ \langle d \rangle = \frac{1}{N(N-1)} \sum_{i \neq j} d_{ij} \]
- **网络效率**：\[ E = \frac{1}{N(N-1)} \sum_{i \neq j} \frac{1}{d_{ij}} \]（图2-25）

---

### 2.7 同质性

**定义**：同类节点连接倾向
\[ h_A = \frac{S_{AA} - P_A}{1 - P_A} \]
**应用**：社交网络种族/年龄聚类（图2-26）

---

## 3. 网络上的其他结构

### 3.1 富人俱乐部

**定义**：度大节点间高连接密度
\[ \phi(k) = \frac{2E_{>k}}{N_{>k}(N_{>k}-1)} \]
**现象**：异配网络也可存在（图2-27）

---

### 3.2 弱连接

**定义**：低权重边或社团间边
**作用**：传递非冗余信息（图2-28）
**经典研究**：格兰诺维特《弱关系的力量》

---

### 3.3 结构洞

**定义**：占据中介位置的节点**度量指标**：

- 有效规模：\[ E_G(i) = \sum_{j} \left(1 - \sum_{q} p_{iq} m_{jq} \right) \]
- 限制度：\[ C_G(i) = \sum_{j} \left(p_{ij} + \sum_{q} p_{iq} p_{qj} \right)^2 \]
  **应用**：企业管理、知识转移（图2-29）

### 1.4 子图中心性

def subgraph_centrality(G, max_iter=100):
A = nx.to_numpy_array(G)
sc = np.zeros(A.shape[0])
for t in range(1, max_iter+1):
A_power = np.linalg.matrix_power(A, t)
sc += np.diag(A_power) / np.math.factorial(t)
return dict(zip(G.nodes(), sc))

### 1.5 k-核

def k_core_decomposition(G):
k_cores = {}
degrees = dict(G.degree())
sorted_nodes = sorted(degrees.items(), key=lambda x: x[1])

for k in range(1, max(degrees.values())+1):
while True:
to_remove = [n for n,d in degrees.items() if d < k]
if not to_remove: break
for n in to_remove:
for neighbor in G.neighbors(n):
degrees[neighbor] -= 1
del degrees[n]
k_cores[k] = set(degrees.keys())
return k_cores

### 1.6 特征向量中心性

def eigenvector_centrality(G, max_iter=100, tol=1e-6):
nodes = list(G.nodes())
x = {n: 1.0 for n in nodes}
for _ in range(max_iter):
x_last = x.copy()
for n in nodes:
x[n] = sum(x_last[neighbor] for neighbor in G.neighbors(n))
norm = np.sqrt(sum(v**2 for v in x.values()))
x = {n: v/norm for n,v in x.items()}
if np.allclose(list(x.values()), list(x_last.values()), rtol=tol):
break
return x

def rich_club_coefficient(G, k):
high_degree_nodes = [n for n in G.nodes() if G.degree(n) > k]
subgraph = G.subgraph(high_degree_nodes)
actual_edges = subgraph.number_of_edges()
max_possible = len(high_degree_nodes)*(len(high_degree_nodes)-1)/2
return actual_edges / max_possible if max_possible !=0 else 0
